# Механика (прототип v0.2)

Все размеры в условных единицах поля. При переносе в Unity удобно взять 1 юнит Unity = 100 единиц поля.

## Поле

| Параметр | Значение |
|---|---|
| Размер поля | 600 × 960 |
| Ширина ворот | 220 |
| Глубина сетки | 36 |
| Радиус героя | 24 |
| Радиус мяча | 13 |
| Радиус штанги | 7 |

## Настраиваемые параметры (ползунки в прототипе)

| Ключ | Что делает | По умолчанию |
|---|---|---|
| `speed` | макс. скорость героя, ед/с | 310 |
| `dribble` | множитель скорости с мячом | 0.88 |
| `turn` | скорость разворота героя, рад/с | 11 |
| `catchSpd` | макс. относительная скорость мяча, при которой его можно подобрать | 800 |
| `kick` | базовая сила удара, ед/с | 950 |
| `charge` | множитель силы при полном заряде | 1.6 |
| `friction` | затухание скорости мяча (exp, 1/с) | 1.0 |
| `bounce` | отскок мяча от бортов и штанг | 0.75 |
| `dashPow` | скорость рывка, ед/с | 880 |
| `dashCd` | перезарядка рывка, с | 2.2 |

## Фиксированные правила

- Ускорение героя: скорость догоняет целевую с коэффициентом 14/с; во время заряда удара скорость ×0.82.
- Удар: дальность R + BR + 18, перезарядка 0.22 с, полный заряд за 0.7 с.
  Сила = `kick × (0.7 + (charge − 0.7) × заряд)`.
  Направление = 65% направление стика + 35% направление «герой → мяч».
- Рывок: длится 0.17 с. Столкновение рывком с соперником: оглушение 0.75 с, отброс 620 ед/с.
- Касание мяча: упругость 0.35 при обычном беге, 1.1 во время рывка.
- Макс. скорость мяча 1700 ед/с.
- Физика: фиксированный шаг 1/120 с.

## Ведение мяча

- Мяч прилипает к «лицу» героя, если касается его в секторе ±70° от направления взгляда (cos > 0.34) и летит медленнее `catchSpd`. Быстрые удары в лицо отскакивают.
- Прилипший мяч стоит в точке `позиция + взгляд × (R + BR + 1)` и двигается вместе с героем. Герой поворачивается с ограниченной скоростью `turn`, поэтому мяч обходит его по дуге.
- Мяч отрывается, когда:
  - владелец бьёт (удар идёт в направлении стика, назад бить нельзя); 0.3 с нельзя подобрать снова;
  - соперник касается мяча своим лицом (отбор); после отбора 0.3 с защиты от обратного отбора, у потерявшего 0.35 с без подбора;
  - владельца оглушили рывком: мяч вылетает, 0.9 с без подбора.
- Если владелец заносит мяч в створ ворот, засчитывается гол.

## Матч

- 1 на 1 против бота, до 5 голов или 3 минуты.
- Сложность бота: скорость ×0.78 / ×0.93 / ×1.05, время реакции 0.24 / 0.13 / 0.06 с, разброс прицела 0.32 / 0.17 / 0.07 рад.
