# Арена Страйкеров

Мобильный аренный футбол на героях со способностями, в духе Banjoball / Dota Strikers.
Вид сверху, короткие матчи, у каждого героя свой набор скиллов.

## План

1. **Браузерный прототип** (`prototype/`) — проверяем, весело ли играть, и подбираем параметры механики.
2. **MVP на Unity** — переносим механику с найденными параметрами, собираем под Android/iOS.
3. Дальше: герои, режим 3v3, онлайн.

## Как запустить прототип

Открой `prototype/index.html` в браузере (на телефоне тоже работает).

- Левая половина экрана — стик
- «Удар» — держи, чтобы зарядить, отпусти, чтобы пробить
- «Рывок» — бросок вперёд, при столкновении оглушает соперника
- Клавиатура: WASD / стрелки, J или пробел — удар, K или Shift — рывок

## Структура

```
prototype/   браузерный прототип (один HTML-файл, canvas + JS)
docs/        дизайн игры и параметры механики
```

Подробности механики и текущие значения параметров — в [docs/mechanics.md](docs/mechanics.md).
